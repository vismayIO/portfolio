## ⚡ Overview

A blazing-fast, minimal, and elegant developer portfolio — crafted with the latest web technologies. Built for performance, accessibility, and beautiful design across every device.

### ✨ Features

- 🎨 **Modern Design** — Clean, minimal UI with smooth animations
- 🌙 **Dark Mode** — Automatic theme switching based on system preference
- 📱 **Fully Responsive** — Pixel-perfect on every screen size
- ⚡ **Lightning Fast** — Optimized with Next.js 16 & React Compiler
- ♿ **Accessible** — Built with a11y best practices
- 🔍 **SEO Optimized** — Meta tags, Open Graph, and structured data
- 🧹 **Clean Code** — Linted & formatted with Biome

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) >= 18
- [Bun](https://bun.sh/) (recommended) or npm/yarn/pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/vismayIO/portfolio.git

# Navigate to the project
cd portfolio

# Install dependencies
bun install

# Start the development server
bun dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

### Build for Production

```bash
bun run build
bun start
```
